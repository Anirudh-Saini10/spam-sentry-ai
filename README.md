# 🛡️ SpamSentry

AI-powered SMS spam and phishing detection system using a fine-tuned DistilBERT transformer model.

## 🚀 Live Demo

https://spam-sentry-ai-ohzyu8xplysuo9jfnzl5tj.streamlit.app/


# 🔥 Features

- Fine-tuned DistilBERT spam classifier
- Real-time SMS threat analysis
- Phishing and scam detection indicators
- Dynamic random spam/safe message generation
- Confidence score visualization
- Interactive Streamlit frontend
- Hugging Face hosted transformer model
- Cloud-deployed NLP inference pipeline

---

# 🧠 Model Architecture

SpamSentry uses:

- DistilBERT
- HuggingFace Transformers
- PyTorch

The model was trained and deployed for binary classification:

- SAFE message
- SPAM / phishing message
